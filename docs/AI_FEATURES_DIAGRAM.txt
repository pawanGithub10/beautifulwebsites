## Data Flow - Complete Example

```
EXAMPLE: Generate AI Product Description
─────────────────────────────────────────

Step 1: User Request
┌─────────────────────────────────────────────────────────────┐
│ POST /api/v1/catalog/{site_id}/products                    │
│ {                                                           │
│   "name": "Organic Green Tea 100g",                        │
│   "category": "Beverages",                                 │
│   "price": 299,                                            │
│   "generate_description": true                             │
│ }                                                           │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
Step 2: Storefront Service
┌─────────────────────────────────────────────────────────────┐
│ • Validate product data                                     │
│ • Create product record in DB                              │
│ • Fetch prompt template for "Beverages"                    │
│ • Build AI generation request                              │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
Step 3: LLM Gateway
┌─────────────────────────────────────────────────────────────┐
│ • Check cache (Redis) for similar prompt                   │
│ • Select model (GPT-4 for first-time, GPT-3.5 for retry)  │
│ • Execute API call to OpenAI                               │
│ • Parse JSON response                                      │
│ • Track token usage (450 tokens = $0.027)                 │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
Step 4: OpenAI API
┌─────────────────────────────────────────────────────────────┐
│ Response:                                                   │
│ {                                                           │
│   "description": "Discover the pure essence of nature...", │
│   "short_description": "Premium organic green tea...",     │
│   "meta_title": "Organic Green Tea 100g | YourStore",     │
│   "tags": ["organic", "tea", "health"]                    │
│ }                                                           │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
Step 5: Save & Return
┌─────────────────────────────────────────────────────────────┐
│ • Save to ai_generated_descriptions table                  │
│ • Update product.description field                         │
│ • Record token usage in ai_token_usage table              │
│ • Cache response for 7 days                                │
│ • Return to client                                         │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
Step 6: Client Response
┌─────────────────────────────────────────────────────────────┐
│ {                                                           │
│   "product_id": "uuid",                                    │
│   "name": "Organic Green Tea 100g",                        │
│   "description": "Discover the pure essence...",           │
│   "ai_generated": true,                                    │
│   "tokens_used": 450,                                      │
│   "generation_time_ms": 1200                               │
│ }                                                           │
└─────────────────────────────────────────────────────────────┘

Total Time: ~1.5 seconds
Total Cost: $0.027
Cache Duration: 7 days (if same product attributes)
```
